# Materials Analysis

This is a domain placeholder, not a complete protocol library. Do not import
bone or vascular assumptions into materials work.

When materials analysis is in scope, define:

- material phases and expected intensity/attenuation relationship
- calibration or density mapping requirements
- segmentation target: pores, solid scaffold, particles, cracks, inclusions,
  coating, or implant/bone interface
- metrics: porosity, pore size distribution, connectivity, surface area,
  thickness, anisotropy, crack length/volume, phase volume fractions
- QC: representative slices, phase overlays, threshold sensitivity, artifact
  regions, and dimensional sanity checks

If the material system needs specialized standards or calibration equations,
research current references before execution.
